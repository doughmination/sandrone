Sandrone

The Marionette’s workshop is operational.

An all-in-one Discord bot: lookups, text and developer tools, media embeds, pride flag avatars, YouTube downloads, and a handful of things that exist purely for fun. Everything is a slash command. Nothing about you is stored.

What she does

Lookups

GitHub users and repositories, Codeberg, Wikipedia summaries, Urban Dictionary, Discord profiles and PluralKit systems — plus a real WHOIS client that speaks the protocol on port 43 and follows referrals to the registrar.

Tools

Around 100 units across 12 categories, case conversion, JSON pretty-printing with a caret under the syntax error, a regex linter that catches catastrophic backtracking, QR codes, and translation that runs offline on the host.

Media

YouTube as MP4 or 192 kbps MP3, X / Twitter and Bluesky posts embedded properly with their video, and thirty pride flags wrapped around a profile picture — still or spinning, one flag or two.

Moods

Sandrone has a personality layer nobody asked for. She refuses roughly one command in ten, and occasionally posts something unprompted in whatever channel is busy. None of it is stored and none of it survives a restart.

Privacy, briefly

Sandrone does not have a database. Nothing about you is stored, nothing is tracked, and there is nothing to sell. Commands are handled in memory and the result is thrown away.

The one exception is /yt-dlp: a download too large to attach is kept on the host for 24 hours behind an unguessable link, then deleted automatically. The file is the YouTube content itself — never anything about who asked for it.

Is this the right bot?

Discord bots get impersonated. The avatar, the name and the “about me” can all be copied exactly — the application ID cannot.

Application ID 1539185764904996974

Sandrone only ever uses three sets of links of its own:

  • discord.com discord.ggDiscord’s own — the invite and the support server.
  • sandrone.is-a.botThe short link. It redirects to the docs.
  • sandrone.doughmination.gayWhere /yt-dlp serves an oversized download.

She will never ask for a password, a token or a 2FA code, never ask you to “re-verify” your account, and never send you a QR code to scan with the Discord app. If something claiming to be Sandrone does any of that, it is not this bot.
